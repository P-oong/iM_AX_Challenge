# 이미지 자산 폴더

이 폴더에 아래 파일명으로 이미지를 넣기만 하면 앱에 자동으로 표시됩니다.
(파일이 없으면 해당 슬롯은 그냥 비워지고, 앱은 정상 동작합니다.)

| 파일명 | 표시 위치 | 권장 크기 |
|---|---|---|
| `logo.png` | 사이드바 최상단 (모든 페이지) | 가로 400px 내외, 배경 투명 권장 |
| `hero.png` | 홈 화면 상단 배너 | 1600×400 내외 (가로로 긴 배너) |
| `briefing_banner.png` | ① 주간 전략 브리핑 페이지 상단 | 1600×300 내외 |
| `background.png` | 앱 전체 배경 (흰색 반투명 오버레이 적용) | 1920×1080 이상, 은은한 패턴/사진 권장 |

- `png` 대신 `jpg` / `jpeg` / `webp` 확장자도 인식합니다. (예: `hero.jpg`)
- 배경 이미지는 가독성을 위해 90% 흰색 오버레이가 덮이므로, 대비가 강한 이미지도 무방합니다.
- 이미지 추가/교체 후 브라우저 새로고침만 하면 반영됩니다 (재배포 불필요, 로컬 기준).
- 배포본(Streamlit Cloud)에 반영하려면 이 폴더째 git에 커밋 후 push 하세요.
